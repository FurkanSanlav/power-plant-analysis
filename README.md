# 📊 Power Plant Output Prediction & Analysis

An AI Engineering project focused on forecasting energy generation and segmenting operational data through advanced Machine Learning techniques.

## 🧠 Model Implementation
* **Supervised Learning:** Developed predictive models using **Logistic Regression**, **KNN**, and **Decision Trees**.
* **Unsupervised Learning:** Utilized **Clustering** algorithms to identify patterns in high-dimensional operational data.
* **Evaluation:** Benchmarked models using **Precision-Recall** metrics and **Cross-Validation** to ensure robustness.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib
